# AI-Powered Student Learning Management System (AI-SLMS)

## Overview

AI-SLMS is a Python-based Student Learning Management System that combines traditional LMS functionality with simple AI-inspired features such as Knowledge Search, FAQ Assistant, Tokenization, and Text Prediction.

The project is built using Object-Oriented Programming (OOP), File Handling, and a CustomTkinter-based graphical user interface.

---

## Features

### LMS Features

* Add Student
* Add Trainer
* Create Course
* Enroll Student in Courses
* Update Learning Progress
* View Students
* View Courses
* Save and Load Data

### AI Features

* Knowledge Base Search
* Tokenization Engine
* FAQ Assistant
* Next Word Prediction

### Data Persistence

* Store and retrieve data using text files
